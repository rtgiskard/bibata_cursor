= Bibata Cursor

image:https://github.com/rtgiskard/bibata_cursor/actions/workflows/build.yaml/badge.svg[build]
image:https://img.shields.io/badge/license-GPLv3-green.svg?style=flat[license]

Bibata cursor themes in scalable SVG, hyprcursor and Xcursor formats.
Based on https://github.com/ful1e5/Bibata_Cursor[Bibata_Cursor],
hand-designed by https://twitter.com/ful1e5[Abdulkaiz Khatri].


== Build

=== Prerequisites

* Python `>= 3.12`
* https://wiki.gnome.org/Projects/LibRsvg[librsvg]: generating PNG files (Xcursor only)
* https://xorg.freedesktop.org[xorg-xcursorgen]: compiling PNG files into Xcursor resources (Xcursor only)

=== Quick Start

Run build commands from the repository root. The output directory must not already
exist; choose a new `--out-dir` when rebuilding.

[source,bash]
----
# 1. install the dependencies
# Arch Linux:  pacman -Syu python librsvg xorg-xcursorgen
# Fedora: dnf install python3 librsvg2-tools xcursorgen

# 2. clone
git clone https://github.com/rtgiskard/bibata_cursor

# 3. build
cd bibata_cursor
./src/cursor_utils.py --svg --hypr --x11 --out-dir ./out

# 4. copy to user local icon theme
mkdir -p ~/.local/share/icons
cp -r ./out/Bibata-* ~/.local/share/icons/
----

== Examples

The following build commands are alternatives, not sequential steps.
Combine format flags to generate multiple formats in the same theme.
Omit `--theme` to build the default theme set.

[source,bash]
----
# Run the utils to check the help:
./src/cursor_utils.py -h

# Generate svg cursor to `./out`:
./src/cursor_utils.py --svg --out-dir ./out

# Generate scalable SVG and Xcursor together for niri and bitmap-only clients:
./src/cursor_utils.py --svg --x11 --theme Bibata-Modern-Classic --out-dir ./out
----

Unknown themes, missing format flags and existing output directories are rejected
with an error on stderr and exit status `2`, without modifying the output directory.


== How It Works

1. recolor SVG according to `config/render.json`
2. parse cursor settings from `config/build.toml` (`config/build.right.toml` for `-Right` themes)
3. generate metadata for scalable SVG, hyprcursor or Xcursor
4. render SVG files to PNG files (Xcursor only)
5. assemble cursor themes, preserving SVG artwork for the vector formats


== Scalable SVG / niri

`--svg` generates `cursors_scalable/<cursor-name>/` directories containing
recolored SVG artwork and `metadata.json`, alongside `index.theme`.
This format requires only Python to build; neither `rsvg-convert` nor `xcursorgen` is used.
It can coexist with `hyprcursors/` and `cursors/` in the same theme by combining the build flags.

For https://github.com/rtgiskard/niri[niri builds with SVG cursor support], install the generated theme as above and select it:

[source,kdl]
----
cursor {
    theme "Bibata-Modern-Classic"
    size 24
}
----

SVG loading is automatic in these niri builds; `xcursor-fallback true` is needed only
if niri should also load Xcursor bitmap resources. Generate `--x11` alongside `--svg`
when applications need the same theme in the traditional bitmap format.

Metadata uses the source artwork's 256-unit nominal size and unrounded hotspot coordinates
from `config/build.toml` or `config/build.right.toml` for `-Right` themes.
Animated frames are ordered numerically and use `x11_delay` in milliseconds.
All configured cursor aliases become relative directory symlinks; `--x11-symlink`
controls only the Xcursor output.


== Customization

=== Customize Sizes

Set `cursor_defaults.x11_sizes` in `config/build.toml`, or in
`config/build.right.toml` for `-Right` themes. Keep only the sizes you need to
reduce the Xcursor theme size. Individual cursor sections can override this list
with `x11_sizes`.
For hyprcursor and scalable SVG, no specific output sizes are needed.

=== Customize Colors

In `config/render.json`, find the target theme and edit the `replace` values in its
`colors` array. Each `match` value identifies a source color:

* `#00FF00`: base color.
* `#0000FF`: outline color.
* `#FF0000`: watch background color.

For example, this entry under `Bibata-Modern-Classic` sets the base color to black:

[source,json]
----
{ "match": "#00FF00", "replace": "#000000" }
----

Rebuild the theme into a new output directory to apply your changes.
